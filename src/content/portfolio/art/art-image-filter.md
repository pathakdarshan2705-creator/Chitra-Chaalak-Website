I built this Image Filter Studio as an exploration of digital degradation and analog aesthetics. Using HTML5 Canvas and native JavaScript, this tool allows anyone to upload an image and apply bespoke filters—ranging from classic black-and-white to my signature Chitra-Chaalak duotone and CRT glitch effects.

The goal was to create a tactile, interactive experience that feels like operating a physical piece of broadcast equipment. You can try it out yourself below!
